# Studio widget library interface

The [iPhone widget-size cleanup](iphone-widget-sizes.md) removes the former XL layout switch and keeps one Extra Large option. This supersedes the earlier multi-layout behavior; saved designs in the retired layout remain recoverable without deleting photos.

## Studio icon accent update

The owner authorized changing all three Studio destination tiles (My Widgets, Counter Widgets and Clipboard) to the selected app accent. The fixed blue/purple icon gradients and blue glows are replaced with the existing shared `AccentSurface` and live `AccentGlow` resource. The exact accent fills each tile; a contrasting black/white vector glyph maintains at least 4.5:1 contrast, including black/white accents. The themed outline remains available for separation from the card. Card shadows use the same accent glow. Decorative icons are excluded from the accessibility tree and remain input-transparent, preserving the full-card native tap target and spoken destination label.

The 70-unit tiles, 36-unit glyphs, layout, destinations, press feedback, saved appearance settings and page lifecycle are retained. Dynamic resources update on Settings changes and resolve from the existing saved accent after relaunch, without new persistence or event subscriptions. Review covered all three destinations, light/dark contrast, accessibility and navigation hit handling. Existing 141 app tests (including shared accent/contrast and live Settings resource coverage), managed iOS C# compilation, source/project checks and whitespace checks pass. No new tests duplicate this small composition change. Native appearance, glows, VoiceOver and tapping each destination still require an iPhone check. The owner subsequently authorized committing and pushing main. No version tag or IPA build is authorized for this update.

## Studio library update in 0.2.20

The owner confirmed the widgets were working after the 0.2.19 gallery-name correction, then authorized this UI update and subsequently its commit, main push and new version tag. This ships with the Home reset action in **0.2.20 (22)**. The owner will monitor the tag-triggered IPA build.

Studio now opens three destinations: My Widgets, Counter Widgets, and the retained Clipboard. The first two follow the supplied reference's rounded blue/purple icon tiles, glass card borders, spacing and chevrons on a plain Light/Dark background. Clipboard stays accessible below the widget cards because removing its entry or functionality was not requested.

My Widgets starts on Small, with Medium, Large and XL filters and no All tab. XL is a single iPhone size with compatibility guidance. Each card shows the saved name, size badge, local updated time, edit/delete controls and an open chevron. A complete composite preview sits below the card header rather than cropping each design into the same square thumbnail. Tapping the image or chevron opens the existing editor. Deletion still requires confirmation and clears assigned slots through the existing service.

Previews use representative canvas sizes: Small 170×170, Medium 364×170, Large 364×382 and Extra Large 364×594. They retain those proportions, stay at their representative size when space permits, and scale down to fit narrower screens. These are representative layout units, not a promise of exact Home Screen dimensions on every device. Existing bounded composite thumbnails preserve all visible layers without decoding every full-resolution source photo. Missing previews offer Edit/save guidance. The Updated label reads the saved render's modification time; no private/shared catalog schema or photo data is rewritten for this display.

The visible Widget slots action opens assignments at the current size. The + button starts a new design in the same size. Supported designs retain their stored size when opened for editing; retired layouts open an unsaved iPhone XL draft as described in the cleanup notes. Filter selections survive trips into the editor/slots within the current page instance; they do not change saved assignments. The back/add header stays outside the scroll area, while headings, filters and cards scroll together to remain usable in landscape and at large text sizes. An extra right gutter keeps the scroll indicator outside card content.

Counter Widgets offers only Small/Medium, one correctly proportioned preview at a time, two indicator dots and Refresh preview. There is no customization, Large or XL option. Previews read the existing shared counter; private fallback values are not presented as shared. Refresh reads the snapshot without incrementing it or changing its appearance. The actual native Counter widget remains unchanged, including its medium blue mark; the reference's decorative blue wave was not added to a preview of an unchanged widget. Counter preview text is scaled as a canvas, with one complete VoiceOver description.

Shared segmented controls and primary actions follow the selected app accent, with contrast-aware text, 44+ unit native hit targets and selected-state accessibility descriptions. Review found that the existing editor-action component calculated contrast at 19 units although its caption was 16. It now uses the actual 16-unit caption size and its Light/Dark tests require 4.5:1 contrast. This applies consistently to the reused Widget slots/Refresh controls and other consumers of that component.

The two widget pages share serialized actions, cancellation on departure, foreground checks after confirmation, activation reloads and an appearance epoch. A read from an earlier page lifetime cannot repaint a newly reappeared page. Failed actions restore enabled controls. The existing editor, photo import/crop sliders, repositories, slot IDs, native registrations, App Group configuration, Clipboard and tag-only IPA workflow remain in use. Direct drag/pinch editing is deferred as requested.
